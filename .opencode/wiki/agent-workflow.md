# Agent Self-Management Workflow

Агенты OpenCode должны самостоятельно поддерживать хаб знаний `agent-skills`:
добавлять новые навыки, обновлять wiki и пушить изменения в GitHub.

## Git-репозиторий

- Локально: `E:\ПлагиныРевит\agent-skills\` (репозиторий `strahser/revit-skills`)
- Remote: `https://github.com/strahser/revit-skills.git`
- Workflow: `main` — единственная ветка, force-push не использовать

## Что должен делать агент

### 1. Добавление нового навыка

Когда агент пишет новый полезный код или обнаруживает паттерн, который нужно сохранить:

1. Создать директорию `E:\ПлагиныРевит\agent-skills\.opencode\skills\{skill-name}\`
2. Написать `SKILL.md` (следуя формату существующих навыков)
3. Обновить таблицу навыков в `.opencode\README.md`
4. Закоммитить и запушить

### 2. Обновление wiki

Когда агент узнаёт новую информацию о проекте (баги, архитектура, конфигурация):

1. **Знание конкретного проекта** → в локальную вики проекта `<проект>\.opencode\wiki\`
   (HeatLossRevit2, MepBimServer, MepTaggingSolution, dev-pipeline, AHUCalculator).
2. **Общее знание** (паттерны, форматы, MCP) → в общую wiki `agent-skills\.opencode\wiki\`.
3. Отредактировать страницу в соответствующей `wiki\` или создать новую.
4. Обновить `wiki\index.md` (локальной или общей вики) — добавить ссылку.
5. Для проектной вики изменения коммитятся в репозиторий проекта (если `.opencode` не в
   `.gitignore`), для общей — в `agent-skills`.

### 3. Обновление конфигурации

Если агенту нужен новый MCP-сервер или дополнительный путь импорта навыков:

1. Отредактировать `~/.config/opencode/opencode.jsonc` (глобальный конфиг)
2. Добавить новый MCP-сервер в `mcp` (НЕ `mcpServers`) или путь скилов в `skills.paths` (НЕ `skills.import`)
3. Закоммитить `agent-skills`, если изменения касаются навыков/wiki

### 4. Синхронизация с GitHub

После любых изменений в `agent-skills\`:

```bash
cd E:\ПлагиныРевит\agent-skills
git add -A
git commit -m "description of changes"
git push
```

## Правила

- Не удалять существующие навыки и wiki-страницы без явной необходимости
- Формат SKILL.md: заголовок H1, описание, секции с примерами
- Формат wiki: markdown, ссылки относительные
- commit message на английском, краткий (до 80 символов)
- После пуша уведомить пользователя: "обновлено в agent-skills"
